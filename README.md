# Online Pharmacy Secure Design

An academic project exploring security considerations in the design of an online pharmacy platform. The report includes secure use cases, abuse cases, an input trust state machine, activity diagrams, and a designer's rationale.

## My contribution

I worked on UC-3: Search Products and View Details, focusing on search input validation, parameterized queries, output encoding, rate limiting, and related abuse cases. I also contributed to the Designer's Rationale.
